## Описание

Программа реализует симуляцию работы библиотеки с использованием пользовательских коллекций и псевдослучайной модели событий. Система управления библиотекой поддерживает добавление, удаление и поиск книг через магические методы Python.

## Основные классы

### Book, RareBook, DigitalBook
Классы книг с базовыми атрибутами (название, автор, год, жанр, ISBN). `RareBook` добавляет стоимость, `DigitalBook` — размер файла.

### BookCollection
Пользовательская коллекция с поддержкой протоколов Python:
- `__getitem__` — доступ по индексу
- `__iter__` — итерация
- `__len__` — размер коллекции
- `__contains__` — проверка наличия

### IndexDict
Словарная коллекция для индексации книг по ISBN, автору и году с быстрым поиском O(1):
- `__getitem__` — доступ по ISBN
- `__iter__` — итерация по ISBN
- `__len__` — количество книг
- `__contains__` — проверка ISBN

### Library
Главный класс с магическими методами:
- `__add__` — добавление книги (`library + book`)
- `__sub__` — удаление книги (`library - book`)
- `__call__` — поиск (`library("автор")`, `library(2000)`, `library("978-...")`)

## События симуляции

- **event_add_book** — добавление случайной книги
- **event_remove_book** — удаление случайной книги
- **event_search_by_author** — поиск по автору
- **event_search_by_genre** — поиск по жанру
- **event_search_by_year** — поиск по году
- **event_search_nonexistent** — поиск по ISBN
- **event_slice_books** — получение среза книг
- **event_update_index** — проверка индексов
